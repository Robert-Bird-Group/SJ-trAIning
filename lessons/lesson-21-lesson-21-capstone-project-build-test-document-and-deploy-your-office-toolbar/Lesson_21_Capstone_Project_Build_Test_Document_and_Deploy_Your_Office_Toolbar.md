# Lesson 21 - Capstone Project: Build, Test, Document, and Deploy Your Office Toolbar

## Final Project Goal

Build a small office-ready pyRevit toolbar supported by documentation, testing, and a rollout strategy.

## Capstone Deliverables

```text
OfficeToolbar.extension/
├── extension.json
├── Company.tab/
│   ├── QA.panel/
│   ├── Sheets.panel/
│   └── Views.panel/
├── lib/
├── docs/
│   ├── adoption_wiki.md
│   └── release_notes.md
└── README.md
```

## Required Documentation

- Toolbar overview
- Tool list
- Installation notes
- Known limitations
- Test checklist
- Release notes
- Support process
- Future backlog

## Presentation Format

Prepare a short walkthrough:

1. What problem does the toolbar solve?
2. Who is it for?
3. What tools are included?
4. How was it tested?
5. How will it be rolled out?
6. What comes next?

## ✅ Lesson Outcome

You complete the course with a practical toolbar package and a clear deployment plan.
