Lesson 01 - Course Orientation and the 90-Day Toolbar Goal

> Style Note > These lessons follow the provided base lesson format: conversational explanation, simple examples first, practical exercises, emojis for orientation, and clear What to do prompts.

Welcome to LRA-Academy 3.0

The goal of this course is simple: build, test, document, and deploy a robust pyRevit toolbar that your office can actually use.

We are not here to create one random script that works once. We are here to build a repeatable workflow where AI helps you move faster, but you still understand the code and stay in control.

🗺️ The 3 Course Phases

Phase 1 - From Code Confusion to Building With Confidence

You will set up your AI Sidekick, learn the Python and pyRevit foundations, and build your first personal pyRevit tool.

Phase 2 - From Fragile Tools to Robust Office Deployment

You will debug, package, document, and prepare tools for real project use and office rollout.

Phase 3 - From Hitting Limits to Unlocking AI-Scale

You will improve your AI workflow with better context, memory, documentation grounding, and self-improvement loops.

🎯 What You Should Build During This Course

By the end of the course, you should have:

  • A working pyRevit extension structure
  • A small toolbar with 2 to 5 useful tools
  • Debugged and user-safe code
  • A simple adoption wiki
  • A rollout and update strategy
  • An AI-assisted workflow for maintaining and expanding the toolbar

🔎 Pick Your First Automation Target

Before writing any code, choose a task that is:

  • Repetitive
  • Annoying
  • Easy to describe
  • Low risk if tested in a sample model
  • Valuable to you or your team

Examples

  • Rename selected views
  • Check sheet numbers
  • Report selected element parameters
  • Find unused view templates
  • Create a quick QA report
  • Place standard drafting views

💪 Simple Exercise

Create a short automation brief.

# My First Tool Idea

## Problem
Describe the repetitive Revit task.

## Current Workflow
How do you do it manually today?

## Desired Result
What should the pyRevit tool do?

## Inputs
What does the user need to select or provide?

## Outputs
What should the tool change, report, or create?

## Risk Level
Low / Medium / High

✅ Lesson Outcome

You now understand the course direction and have selected a practical automation idea to carry into the next lessons.
