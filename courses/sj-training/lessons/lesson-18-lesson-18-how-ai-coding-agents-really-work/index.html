Lesson 18 - How AI Coding Agents Really Work

AI Is Powerful, But Not Magic

AI coding agents predict useful responses based on context. If context is weak, the answer can be weak.

Key Concepts

  • Tokens: chunks of text the model reads and writes
  • Context window: how much information AI can consider at once
  • Memory: stored knowledge or preferences across tasks
  • Grounding: connecting AI to reliable project or API information
  • Hallucination: confident but incorrect output

Practical Rules

  • Provide project context
  • Ask for assumptions
  • Ask for test cases
  • Verify Revit API calls
  • Never run unknown code blindly
  • Keep sensitive data out unless approved

💪 Simple Exercise

Ask AI to explain one of your scripts, then ask it to list likely failure points. Compare the response against your own testing.

✅ Lesson Outcome

You understand why AI results vary and how to improve them with better context.
