# Lesson 20 - Self-Iterating AI Workflows and Advanced Automation Experiments

## What is a Self-Iterating Loop?

A self-iterating workflow asks AI to propose, build, review, test, and improve a tool in repeated cycles.

You still stay in charge. AI suggests. You approve.

## Safe Iteration Loop

1. Define the goal
2. Generate a simple version
3. Review assumptions
4. Create test cases
5. Run tests manually
6. Paste results back to AI
7. Improve one thing
8. Repeat

## Example Prompt

```text
Here is my current script and test result.
Do not rewrite from scratch.
Identify the smallest safe change to fix the issue.
Explain why it works before giving code.
```

## Advanced Experiment Ideas

- AI-generated test plans
- AI-written documentation drafts
- Tool changelog generation
- QA checklist tools
- Model health report tools
- External data preparation before importing into Revit

## 💪 Simple Exercise

Run one improvement loop on your capstone tool and document before/after behaviour.

## ✅ Lesson Outcome

You can use AI iteration safely without losing control of your tools.
