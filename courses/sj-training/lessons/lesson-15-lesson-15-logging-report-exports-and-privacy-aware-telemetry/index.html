What This Lesson Assumes

You already understand the introductory version of this topic from the previous course. This lesson focuses on applying that knowledge to a deployable, maintainable, AI-assisted pyRevit workflow.

Objectives

  • Decide what tool activity should be logged.
  • Create useful logs without collecting sensitive project information unnecessarily.
  • Use exports to support model QA and adoption feedback.

Why Log?

Logs help answer:

  • What version ran?
  • What failed?
  • How often is this tool used?
  • Which checks produce the most issues?

What Not to Log by Default

Avoid logging:

  • Client names
  • Project names
  • Building addresses
  • Model paths
  • Confidential comments
  • Personal user data beyond what your organisation approves

Suggested Log Row

| Date | Tool | Version | Revit | Result | Processed | Warnings | Errors |
