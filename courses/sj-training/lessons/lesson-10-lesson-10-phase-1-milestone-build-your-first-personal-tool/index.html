Lesson 10 - Phase 1 Milestone: Build Your First Personal Tool

Build one working pyRevit tool that solves a real task and that you can explain line by line.

Lesson Content

Milestone Goal

Build one working pyRevit tool that solves a real task and that you can explain line by line.

Tool Requirements

Your tool should include:

  • A clear tool name
  • A simple user workflow
  • Readable Python code
  • Basic comments
  • Basic error handling
  • A short README
  • At least 3 test cases

Suggested Tool Types

Choose a low-risk tool first.

  • Report selected element data
  • List views or sheets
  • Check naming patterns
  • Rename selected views in a test model
  • Export a simple text report

🧪 Test Cases

Create a test checklist.

# Test Checklist

- [ ] Works with valid selection
- [ ] Handles empty selection
- [ ] Handles unexpected element types
- [ ] Shows useful output
- [ ] Does not modify model unexpectedly

💪 Submission Exercise

Create a folder for the tool containing:

ToolName.pushbutton/
├── script.py
└── README.md

✅ Lesson Outcome

You have completed your first proper pyRevit tool milestone.
