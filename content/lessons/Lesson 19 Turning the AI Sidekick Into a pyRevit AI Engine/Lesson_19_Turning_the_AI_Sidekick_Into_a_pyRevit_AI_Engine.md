# Lesson 19 - Turning the AI Sidekick Into a pyRevit AI Engine

## From Assistant to System

An AI Sidekick answers prompts. An AI Engine has reusable context, standards, examples, and workflows.

## Useful Context Files

```text
_ai_sidekick_context.md
_tool_standards.md
_revit_versions.md
_known_api_patterns.md
_deployment_rules.md
```

## What To Include

- Tool folder structure
- Naming conventions
- Common helper functions
- Company drafting principles
- Revit version constraints
- Preferred UI patterns
- Testing checklist

## Prompt Template

```text
Use my pyRevit tool standards and review this script.
Focus on safety, readability, Revit API correctness, and deployment readiness.
Return:
1. Issues
2. Suggested improvements
3. Revised code only after explaining the plan
```

## 💪 Simple Exercise

Create a `_tool_standards.md` file for your toolbar.

## ✅ Lesson Outcome

You can give AI reusable context so it becomes a stronger development partner.
